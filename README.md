# Escape the Dungeon

A simple Mario-style 2D platformer game built in **Java** using **Object-Oriented Programming (OOP)** principles.

## 🎮 Features

- Player movement: jump, run, and interact with the environment
- Basic enemy AI 
- Collectible items (health, key)
- Score tracking
- Game-over and restart mechanics

## 🛠️ Technologies Used

- Java (JDK 8+)
- Java Swing (or JavaFX) for GUI rendering
- Object-Oriented Programming (inheritance, polymorphism, encapsulation)
- MVC architecture (optional)
- Custom game engine logic

## 📁 Project Structure
├── res/
├── sound/
├── src/
│ ├── game/ # Game loop, window, main class
│ ├── entities/ # Player, enemies, items
│ ├── levels/ # Level design and management
│ ├── utils/ # Helpers like collision detection, asset loading
│ └── assets/ # Images, sounds


## 🚀 How to Run
1. Make sure you have Java (JDK 8 or above) installed:
2. Open the file game via code editors (vs Code, esclipe...)
3. Navigate to this path src/main/Main_Class.java, then run it
